Тема: Разработка приложения для анализа и прогнозирования значений волатильных временных рядов.

Разработчикам и аналитикам, работающим с волатильными временными рядами (например, финансовыми или индустриальными метриками), нужно приложение для удобного анализа данных и построения прогнозов на базе моделей машинного обучения.

Пользователи: сотни разработчиков, дата-аналитиков и исследователей, тысячи потенциальных пользователей из бизнеса и науки.

Требования:
- загрузка данных временного ряда в формате .csv
- выбор столбцов даты/времени и целевого показателя при загрузке
- возможность проанализировать данные целиком или выбранный временной интервал
- базовый статистический анализ и вычисление показателей волатильности
- построение графиков
- обучение модели машинного обучения на загруженных данных для прогнозирования будущих значений
- оценка качества модели (например, через метрики MSE, MAE и др.)

Дополнительный контекст:
Приложение ориентировано именно на волатильные временные ряды — данные, значения которых существенно и непредсказуемо изменяются во времени (скачки, резкие пики, периоды высокой и низкой активности). Предполагается работа с потенциально большим объёмом данных и необходимостью наглядной визуализации результатов анализа и прогноза.
